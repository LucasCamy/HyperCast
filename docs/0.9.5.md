# HyperCast 0.9.5

- **Escolher sala** mantém a largura compacta e cresce na vertical conforme as salas carregam. O campo de nome e o botão de atualizar ficam visíveis, e só a lista rola quando falta espaço.
- Ao ligar a webcam, o cartão **Minha câmera** aparece na sala no Windows e no Linux. Clique no cartão para destacar a imagem ou use o ícone de olho para ocultar as prévias locais enquanto a câmera e o compartilhamento continuam para os espectadores.
